# M30 VPN — Build on GitHub from a phone

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open **Actions**.
4. Select **Build M30 VPN APK**.
5. Tap **Run workflow**.
6. When the build finishes, open the workflow run and download **M30VPN-debug-apk** under Artifacts.

The APK is a debug-signed APK intended for testing/installation. It does not require a private release keystore.
